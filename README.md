# Chaqiruv xat

Excel ma'lumotlaridan Word hujjatlar yaratish uchun **frontend-only** web dastur.

Hozirgi bosqich: UI, loyiha tuzilmasi va fayl yuklash. Excel/Word processing keyingi taskda ulanadi.

Fayllar faqat brauzer xotirasida saqlanadi, serverga yuborilmaydi.

## Ishga tushirish

```bash
npm install
npm run dev
```
